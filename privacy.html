Privacy Policy

Last updated: November 20, 2026

This privacy policy describes how the Cruise_gm application ("the Application") handles information. The Application is a personal, non-commercial, open-source command-line tool operated by an individual developer ("we", "us") solely for the purpose of exporting emails from the operator's own Gmail account to local files.

1. Information We Access

The Application accesses the following information through the Google Gmail API, using the read-only scope https://www.googleapis.com/auth/gmail.readonly:

  • Email message metadata (sender, recipients, subject, date, labels);
  • Email message content (plain-text body and snippet);
  • Attachment metadata (file name, MIME type, size). Attachment contents are not downloaded.

Access is limited to the Gmail account whose owner explicitly completes the Google OAuth 2.0 consent flow. The Application does not access any other Google service data.

2. How We Use the Information

The accessed information is used for a single purpose: exporting the user's own emails, for a user-specified date range, into JSON files stored on the user's own computer. The information is not used for advertising, profiling, analytics, machine-learning training, or any other purpose.

3. Where the Information Is Stored

All data retrieved by the Application is stored exclusively on the local computer on which the Application is run. OAuth credentials (refresh token) are stored in a local file with restricted file-system permissions. No data is transmitted to, stored on, or processed by any server operated by us or by any third party, other than the direct API connection to Google's servers required to retrieve the data.

4. Sharing of Information

We do not share, sell, rent, transfer, or disclose any information accessed by the Application to any third party. The data never leaves the user's own computer.

5. Data Retention and Deletion

Because all data resides on the user's own computer, the user retains full control at all times. The user may delete the exported JSON files and the stored credentials at any time using ordinary file deletion, after which no copy of the data remains. The user may also revoke the Application's access at any time via their Google Account permissions page.

6. Security

The Application communicates with Google services exclusively over HTTPS. OAuth credentials are stored locally with owner-only file permissions (mode 600). We recommend users keep their operating system up to date and protect access to their computer.

7. Google API Services User Data Policy

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to This Policy

If this policy changes, the updated version will be published at this URL with a revised "last updated" date.
