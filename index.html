Cruise_gm

Cruise_gm is a personal, open-source command-line tool that exports emails from the owner's own Gmail inbox to local JSON files for personal archiving and analysis.

  • Runs entirely on the owner's own computer.
  • Accesses Gmail through the official Gmail API with a read-only scope (gmail.readonly).
  • Stores all exported data locally; nothing is sent to any third-party server.

This tool is operated by an individual for personal use only and is not a commercial service.
